Blender workspace

  • Click inside the desktop to give Blender keyboard focus. The toolbar sends shortcuts that browsers may otherwise intercept.
  • Use File → Import → glTF 2.0 to open the game's models in public/models/. Save editable projects in art/blender/.
  • Export game-ready meshes with File → Export → glTF 2.0, choosing glTF Binary (.glb).
  • This cloud desktop uses CPU graphics. Solid shading is best for modeling; complex rendered previews can be slow.
  • Closing Blender reopens it. Save your work before restarting the desktop service. Reloading this browser page keeps Blender running.
