How to interpret this comparison

FPS is the count of measured frame intervals divided by elapsed time. Lower frame times are better. Scene-ready time includes engine loading and asset initialization; it is measured with local serving and the current browser cache. The sandbox uses CPU graphics, so these results do not predict a player's GPU performance. Download JSON for raw frame intervals and environment details.
